# firmware

Logical HackHaste for programmable boards. OS packages remain outside this tree.

- `qmk/keymaps/hackhaste/` — layer 0 main, layer 1 left-hand, Caps scancode = Left Control
- `zmk/boards/shields/hackhaste/hackhaste.keymap` — same two layers
- `via/hackhaste-keycodes.json` — same sequence for a board-specific VIA dictionary

Shift state is the US shift of each keycode. No separate symbol layer.
